# The Cipher of Eternal Dawn

An interactive puzzle game for **The Price of Dawn** D&D campaign. Players recover three fragments of Archmagister Corven's notation system to decode the Ritual of Eternal Dawn.

## Live Demo
Play at: https://dn-d-kamitor.github.io/The-Price-of-Dawn/cipher-game/

## Files
- `index.html` — Interactive web game (GitHub Pages)
- `cipher-manuscript.html` — Printable manuscript (PDF via browser print)

## The Cipher System

Three fragments, each held by a different keeper:

| Fragment | Section | Symbols | Letters | Recovery |
|----------|---------|---------|---------|----------|
| I | I of III | 10 geometric | T,E,N,L,I,G,H,B,R,S | Session 1 - Resonance Box |
| II | II of III | 11 geometric | W,A,C,D,F,O,U,M,P,V,Y | Session 2 - Resonance Box |
| III | III of III | 5 geometric | J,K,Q,X,Z | Session 3 - Theron's Archive |

**Total: 26 symbols = complete alphabet**

## The Decoded Truth

When all three fragments are combined, the center notation reveals:

```
INVERSION PATH
WILLING RELEASE
ALL TEN · EXACT MOMENT
SUN RETURNS
ONE UNWILLING → DESTRUCTIVE
```

**The ritual runs through the Dawnborn.** Their post-Silence adaptation is the mechanism. They are not observers. They are components.

## For Teachers

This cipher demonstrates:
- **Substitution cipher with divided key** — No single fragment can decode the full message
- **Shared secret / collaboration requirement** — Three parties must converge
- **Geometric encoding** — The Dawnmark constellation positions map to the cipher order
- **Progressive disclosure** — Hints unlock as students recover fragments

## Usage in Campaign

1. **Session 1**: Players find Fragment I (brass cylinder) → "THE LIGHT IS STILL THERE · SUN RETURNS"
2. **Session 2**: Players find Fragment II (matching cylinder) → "THE PATH · WILLING RELEASE · ALL TEN · EXACT MOMENT"
3. **Session 3**: Players find Fragment III (Theron's archive) → Complete alphabet, full ritual text

## Printing the Manuscript

Open `cipher-manuscript.html` in browser → Print → Save as PDF. Designed for A4 with aged parchment styling.

Pure HTML/CSS/JS — no build step, no dependencies. Works offline. Fonts loaded from Google Fonts.
