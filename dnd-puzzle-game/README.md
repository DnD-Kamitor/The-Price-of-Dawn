# Dungeons & Dragons Puzzle Game

A fun online mini-game for D&D players featuring logic puzzles and riddles.

## Features
- Interactive puzzle challenges
- Multiple difficulty levels
- Score tracking
- Localhost deployment

## Installation

```bash
cd dnd-puzzle-game
npm install
```

## How to Play
1. Start the server with `npm start`
2. Access the game at `http://localhost:3000`
3. Solve the puzzles to progress through the campaign
